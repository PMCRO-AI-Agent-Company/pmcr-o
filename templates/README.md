# Instantiating this template

1. Replace `ProjectName` in solution, projects, namespaces, and folders.
2. Keep PMCR-O routes (`/pmcro:*`) and protocol types (`PmcroRequest`) unless you fork the protocol.
3. Copy `pmcro-skills` marketplace or bind your own `*-skills` marketplace.
4. Set `authority.register/grant/activate` only through governed lifecycle — not by editing defaults to true in the template.
