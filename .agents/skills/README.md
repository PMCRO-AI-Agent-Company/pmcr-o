# Project skill projections

This directory is populated by governed PMCR-O INIT/project-skill projection from canonical global marketplace skills declared in `.agents/application.json`.

Canonical ref format: `<marketplace>/<plugin>/<skill>`.

Projected skill packages are IDE-discovery copies only. Their presence here does not register, grant, activate, install runtime dependencies, or invoke them. `.projection-receipt.json` records canonical sources and file hashes.
